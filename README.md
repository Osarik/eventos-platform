# eventos-platform

Repositorio preparado para alojar una aplicacion Next.js desplegable en Vercel.

## Estado actual

Este directorio solo contiene configuracion base del repositorio. No se detecto una aplicacion Next.js ni un `package.json`, asi que no hay comando de compilacion que ejecutar todavia sin crear codigo funcional nuevo.

## Desarrollo

Cuando la aplicacion Next.js exista, instala dependencias y valida el build con:

```bash
npm install
npm run build
```

## Despliegue en Vercel

1. Conecta este repositorio en Vercel.
2. Usa el framework preset `Next.js`.
3. Define las variables de entorno necesarias en el panel de Vercel.
4. Despliega desde la rama principal.
